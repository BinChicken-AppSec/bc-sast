# Diagrams

Every diagram here is a Mermaid source block inside a Markdown file, so
GitHub renders it natively: nothing to install, nothing to regenerate, and
the source is the thing you edit. The one exception is the precision chart,
which is a generated SVG because Mermaid's `xychart-beta` overlays two bar
series instead of grouping them and has no legend.

| File | What it shows |
|---|---|
| [`pipeline.md`](pipeline.md) | The S0-S11 pipeline: what each stage consumes and produces, the budget gate and what a cap trip does and does not stop, S5's deterministic gate chain, S7's dedup tiers, S10's six safety gates, and S11's weighted validation gates. |
| [`seed-plane.md`](seed-plane.md) | Step 0 end to end (tree-sitter extractors per language, facts, the source/sink corpus, the taint walk and its evidence, framework routes and auth guards), and how S1, S3, S4, S5 and S6 each consume the result. |
| [`guard-gate.md`](guard-gate.md) | A sequence diagram of one "missing authorization" finding meeting the route gate and then the verifier: what makes the gate fire, the three ways it matches a route, and the vetoes that send a finding to the verifier anyway. |
| [`deployment.md`](deployment.md) | The four deployment shapes: the recommended prebuilt-image-on-an-ephemeral-runner PR flow, scheduled and batch full scans with checkpoint resume, the hosted-runner variant and its trade-offs, and the trust boundaries the scanner enforces. |
| [`crate-map.md`](crate-map.md) | All 47 workspace crates grouped into 16 tiers, with the group-level dependency edges, plus the edges whose shape is not what a reader would guess. |
| [`finding-lifecycle.md`](finding-lifecycle.md) | One finding from S4 birth through the S5 gates, the S6 verdict, S7 canonicalization, S8 chaining, into the report's sections, and out to a PR comment, including the three id functions and the three-tier comment matching that keep comments from duplicating. |
| [`precision-by-language.svg`](precision-by-language.svg) | Grouped bar chart of per-language precision, Python harness vs Rust port. Generated by [`gen/precision_chart.py`](gen/precision_chart.py), standard library only. Run `python3 docs/diagrams/gen/precision_chart.py` to regenerate. |

The measurements these diagrams refer to live in
[`../comparison.md`](../comparison.md).

`solution-design.drawio` is an editable copy of the higher-level diagrams in
[`../solution-design.md`](../solution-design.md); it is not part of this set.
